Chủ đề: Các mức ưu tiên của bộ chọn (Specificity) & Từ khóa !important

1. Nội dung trọng tâm lý thuyết

Độ ưu tiên (Specificity) xác định quy tắc CSS nào được trình duyệt áp dụng khi có nhiều bộ chọn cùng hướng đến một phần tử HTML.

Bộ chọn (Selector) Cú pháp Điểm trọng số Mức độ ưu tiên
!important property: value !important; Vô hiệu hóa trọng số Cao nhất
ID Selector #id-name (0, 1, 0, 0) Thứ 2
Class Selector .class-name (0, 0, 1, 0) Thứ 3
Tag Selector img, p, div (0, 0, 0, 1) Thấp nhất

2. Minh họa xử lý xung đột Style trên trang web

Thực nghiệm quy tắc xung đột giữa các bộ chọn trên cùng một đối tượng hình ảnh:

Kết quả áp dụng Style:

• Viền ảnh hiện tại có màu: Xanh Dương (ID Selector thắng)

• Nguyên nhân: Cả img (Xám), .photo-frame (Cam) và #featured-portrait (Xanh) cùng định nghĩa màu viền, nhưng trình duyệt ưu tiên chọn ID do có độ ưu tiên cao hơn Class và Tag.

Ghi chú khi làm báo cáo:
  • Thứ tự ưu tiên: ID > Class > Tag.
  • Từ khóa !important: Có quyền lực cao nhất, dùng để ghi đè mọi quy tắc khi thực sự cần thiết.
